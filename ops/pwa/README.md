# Fizira PWA — установка с главного экрана

Для iPhone в Safari открыть `https://app.fizira.com`, нажать «Поделиться» → «На экран Домой» → «Добавить». Если предлагается опция «Открывать как веб-приложение», включить.

Это не отдельная нативная iOS-программа. Установка бесплатна и работает с действующим сайтом.

## Безопасность и ограничения

- Service worker сохраняет **только** публичный `offline.html`. HTML, JS, токены, API, фотографии и карточки пациентов в Cache Storage не сохраняются.
- Без сети действия в расписании и карточках недоступны; показывается объяснение.
- После развёртывания проверить вход, выход, восстановление пароля, загрузки фото, голосовой ввод, родительский кабинет и навигацию на настоящем iPhone.
- Изменения в этом PR не деплоятся автоматически. Ручной деплой использует резервную копию/откат; перед ним сверить main с продакшеном, так как текущий index.html может не совпадать с live.
- Генератор `ops/pwa/generate-icons.py` требует Pillow==12.0.0. Workflow создаёт три PNG из текущего бренд-символа и включает их в архив развёртывания.
