# Резервное копирование Fizira

`create-backup.sh` создаёт согласованный контрольный снимок текущего российского
Supabase:

- PostgreSQL custom dump со схемами Auth и данными приложения;
- физические объекты Storage;
- исходники Edge Functions;
- контрольные суммы SHA-256 и несекретные метаданные.

По умолчанию результат создаётся в `/root/fizira-backups/<UTC timestamp>` с
правами только для root. Частичный снимок удаляется при ошибке, а успешным
считается только архив, который прошёл проверку `pg_restore`, `tar` и SHA-256.

## Запуск

```bash
sudo bash create-backup.sh
```

Можно переопределить пути переменными `FIZIRA_PROJECT_ROOT`,
`FIZIRA_BACKUP_ROOT` и имя контейнера через `FIZIRA_DB_CONTAINER`.

## Ограничение

Локальная незашифрованная копия на том же сервере защищает только от части
ошибок. Она не защищает от потери сервера или доступа root. Следующий
обязательный этап — шифрование, выгрузка в отдельное российское объектное
хранилище и контрольное восстановление на чистом окружении.

Файл `.env`, JWT и другие секреты этим сценарием намеренно не копируются, пока
не настроено шифрование и отдельное хранилище.
